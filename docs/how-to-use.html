What it is

Rebuild what a part should cost — from first principles.

Instead of accepting a supplier's price, break any bought part or service into its true cost drivers: material, process, labour, overhead, and margin. Link them to live commodity indices, then benchmark quotes line-by-line.

🧱

Transparent

Every driver is visible and editable — no black box.

📈

Defensible

Bound to real commodity indices, so it re-prices as markets move.

📤

Portable

Export to Excel with the formulas intact.
